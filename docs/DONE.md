## 프로필 (#12)
- [x] User 화면의 Edit profile에서 프로필 사진과 소개를 바꾸고, 앱을 다시 켜도 보인다
- [x] 채팅방에서 다른 사람 메시지 옆에 그 사람의 프로필 사진이 보이고, 누르면 아이디와 소개가 나온다
- [x] 다른 사람이 프로필 사진 자리에 이미지 데이터가 아닌 값(외부 URL 등)을 넣어도 화면에 쓰이지 않는다
- [x] 비밀번호를 바꾼 뒤 새 비밀번호로 로그인되고, 예전 비밀번호로는 로그인되지 않는다
- [x] 현재 비밀번호가 틀리면 비밀번호가 바뀌지 않는다

## 방 나가기 (#41)
- [x] 방을 나가면 내 방 목록에서 사라진다
- [x] 다른 멤버가 방을 다시 열면 멤버 목록에 나간 사람이 없고, 나간 사람의 예전 메시지는 그대로 보인다
- [x] 나간 기록이 원장에 leave로 남고, 다시 들어오면 멤버로 돌아온다
- [x] 암호화 방은 나간 뒤 다시 들어가려면 비밀번호나 초대가 필요하다
- [x] 방이 열려 있는 동안 다른 멤버가 나가거나 다시 들어오면, 방을 다시 열지 않아도 멤버 목록에 반영된다
- [x] 방이 열려 있는 동안 다른 멤버가 프로필을 바꾸면, 방을 다시 열지 않아도 반영된다

## 방 목록 보안 (#85)
- [x] 다른 계정이 예전 공용 목록(`footprint/entered/<아이디>`)에 방을 넣거나 지워도 내 방 목록이 바뀌지 않는다
- [x] 아이디가 같은 두 계정의 방 목록이 섞이지 않는다 (목록이 공개키별 사용자 공간에 있어 구조상 분리됨, e2e로는 확인하지 않음)
- [x] 기존 계정은 옮긴 뒤에도 예전에 들어간 방이 목록에 보인다
- [x] 나간 방은 다시 로그인해도 예전 목록에서 되살아나지 않는다

## 메시지가 많은 방 (#45)
- [x] 화면에는 최근 메시지 50개만 그리고, 맨 위로 스크롤하면 이전 50개가 이어서 나온다
- [x] 이전 메시지가 나올 때 보고 있던 위치가 유지된다
- [x] 위로 스크롤해 읽는 중에 새 메시지가 와도 보던 메시지가 화면에서 밀려나지 않는다 (단위 테스트. 방을 연 직후 메시지가 아직 도착하는 동안은 예외, `docs/ideas.md` 참고)
- [x] 방 해시는 화면에 그린 개수와 상관없이 모든 메시지 기준으로 맞는다 (코드로 확인: 해시는 화면 목록이 아니라 받은 메시지 전체(`stored`)로 계산)
- [x] `npm run e2e:load`로 5,000개 방의 최근 메시지 표시 시간과 위로 스크롤 대기 시간을 바꾸기 전후로 측정해 기록한다
