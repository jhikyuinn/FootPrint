# 방 이름 접두사 대신 이름 검사 (#31)

- 지적/발견: 이슈에는 방 노드에 `footprint/room/` 접두사를 붙이는 방법이 적혀 있었다. 코드를 보니 입력창은 이미 `/`, `~`를 막고 있었고, 막히지 않은 길은 초대(API로 들어오는 방 이름)뿐이었다.
- 판단: 접두사는 반영 안 함. 모든 입장 경로가 지나는 `Chat.js`의 `prepare()`에서 같은 이름 규칙(`ROOM_NAME`)으로 검사하도록 함.
- 이유: `/`와 `~`가 막히면 다른 노드에 닿을 수 없어 목적이 같고, 접두사를 붙이면 기존 방의 멤버 목록과 호환이 깨진다. 검사를 한 곳에 두면 새 입장 경로가 생겨도 빠지지 않는다.
