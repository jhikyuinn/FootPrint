# 로그인 유지: 비밀번호 대신 키 쌍을 보안 저장소에 (#11)

- 지적/발견: 로그인을 유지하려면 무언가를 기기에 저장해야 한다. 비밀번호를 저장하면 시작할 때마다 키 유도를 다시 하고, AsyncStorage는 암호화되지 않는다.
- 판단: 반영함. SEA 키 쌍과 아이디를 `expo-secure-store`(Keychain / Keystore)에 저장하고, 시작할 때 `auth(pair)`로 로그인한다.
- 이유: node에서 재 보니 키 쌍 로그인은 네트워크 없이 약 1ms에 끝났다. GUN은 키 쌍으로 로그인하면 아이디 자리에 공개키를 넣기 때문에 아이디를 함께 저장해 되돌려 준다. 웹은 보안 저장소가 없어 매번 로그인하도록 남겨 두었다.
