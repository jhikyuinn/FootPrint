# iOS 회의록 내보내기: 원인을 비교 시험으로 확인 (#79)

- 지적/발견: iPhone에서 Export Minutes를 누르면 메뉴만 닫히고 공유 창이 뜨지 않았다. 코드는 메뉴 모달을 닫은 직후 공유 창을 띄우고 있었다. 처음 몇 번의 시험은 Metro를 `CI=1`로 켜서 휴대폰에 새 코드가 반영되지 않은 결과였다.
- 판단: 반영함. 공유 창을 먼저 띄우고, 공유가 끝나면 메뉴를 닫도록 순서를 바꿨다.
- 이유: 같은 방(메시지 4개)에서 두 순서를 비교했다. 메뉴를 먼저 닫으면 공유 결과가 오지 않았고, 공유를 먼저 하면 "파일에 저장"까지 됐다. 필요 없는 변경을 넣지 않으려고 원래 순서로 되돌려 실패를 다시 확인한 뒤 반영했다.
